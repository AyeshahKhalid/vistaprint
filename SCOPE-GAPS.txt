PART 4 — MISSING: THE DESIGN STUDIO (BIGGEST ITEM)
--------------------------------------------------------------------------------

On vistaprint.com, every product page offers three ways forward:

    1. "Browse our templates"  -> template gallery, then an editor
    2. "Upload your design"    -> file upload, then an editor
    3. "Get a quote"           -> for very large orders (50,000+)

The editor ("design studio") lets customers add and edit text, logos and images,
preview the design on different paper stocks, see upgrade pricing, and it checks
image quality (blur / low resolution) before allowing checkout.

Status: NOT in Figma. NOT in the sitemap.
UPDATE 18 Sept: a first working version of the editor is now built in the
browser (canvas at real print size with bleed/safety guides, text, image
upload, shapes, background colour, templates, undo/redo, zoom, preview, save,
then "Next" into the cart). Still to come: the graphics/pattern library,
front-and-back sides, PDF/AI uploads, and templates whose text can be edited.
It has no Figma design, so it follows vistaprint's layout and our colours.

This is the core of the Vistaprint product. It is a full design application, not
a web page. It needs a design pass and a decision on how far to take it.

--------------------------------------------------------------------------------
PART 6 — MISSING: SIGN IN, ACCOUNTS AND ORDER HISTORY
--------------------------------------------------------------------------------

The real site has a complete account system:

  Sign in        - email and password, OR social sign-in with Google, Facebook
                   or Apple. Hosted on a separate login domain.
  Create account - email or the same three social providers.
  My Account     - payment methods, saved delivery addresses, order history,
                   saved design projects, communication preferences, and a
                   security section for changing passwords.
  My Projects    - where designs from the design studio are saved.
  My Favorites   - saved products per customer.
  Guest checkout - customers can order with no account, then create one from the
                   order confirmation page, or later link the order by entering
                   the order number under "Order History & Reorder".

Status: NOT in Figma. Not built. The backend currently has no login system.

Important knock-on effect: the sitemap marks "Reorder Business Cards" as an
expected page. Reordering is impossible without accounts and order history, so
that page depends entirely on this missing layer.

PART 8 — SMALLER DISCREPANCIES
--------------------------------------------------------------------------------

a) Deals page is the wrong type of page.
   Figma shows the Deals page as identical to the homepage, so we built it that
   way. The real vistaprint.com Deals page is a filtered product listing with
   sidebar filters and pagination. The sitemap's 8 Deals entries (All Deals,
   Business Card Deals, Military Discount, etc.) look like filtered views of
   that listing, not separate pages.

b) A whole category is missing from the sitemap.
   vistaprint.com's main navigation includes "Logo, Websites & Social". It does
   not appear in the sitemap document.

c) No search.
   The real site has a search box in the header with a search results page.
   Not in Figma, not in the sitemap.

d) Help Centre and legal pages.
   Listed in the sitemap as pending, with no designs.

e) Unclear status marks.
   The sitemap uses green ticks and hourglass symbols. We assumed the tick means
   "this page is in scope" rather than "this page is already built", because
   items like Glossy and Uncoated are ticked but have not been built. Please
   confirm which meaning is intended, as it changes how we read the document.

WHAT WE RECOMMEND DOING NEXT
--------------------------------------------------------------------------------

While the questions above are being answered, the most useful work that does not
depend on any of them is fixing the 290 broken navigation links. We would do this
by building a shared sub-category page template driven by data, so every menu
link opens a real page instead of an error.

become available.
